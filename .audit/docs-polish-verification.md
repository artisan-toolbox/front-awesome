## Design and defects found through interaction

Two independent designs examined native Page slot replacement and smaller base composition. The selected direct-owner composition uses native header/default regions while keeping the application's two outline/navigation breakpoints, sidebar scroll owner, mobile panel, Inertia destinations and cookie/prepaint controller. Both designs identified that a full native navigation slot migration would introduce a modal Drawer and a different scroll/focus contract. The shared focused skip-link rule styles a public CSS part once. Page itself does not override Tailwind's spacing unit.

The nested Page demo exposed an upstream global helper. A desktop ancestor Page hides descendant data-toggle-nav controls even when an inner Page is mobile. The native navigation-toggle slot gives the inner Page its own toggle boundary. Auto menu width and native Button link styling keep the compact grid and Drawer content on their intended native geometry. These are structural public API choices, not shadow mutations or component-specific reset rules.

A cold fragment load initially measured the heading before asynchronous WA upgrades changed the document. The retained diagnostic showed scroll 5860 while Skeleton ended at -1100.625px. Waiting only for Page did not solve it. The owning DocsLayout now waits for rendered native hosts' first update and a layout frame before positioning an initial/visit fragment. The documented Inertia navigate type excludes history restoration. A real search-result visit reproduced the persistent-layout case; the same maintained gate now checks both cold visits and reloads. It also leaves for Welcome and returns through history, proving the recorded reading position survives. The test waits for Inertia's own scroll snapshot before leaving instead of racing its deferred save.

The failed-before Skeleton and Tooltip logs are retained at `/tmp/atb-polish-demo-before.log` and `/tmp/atb-polish-tooltip-before.log`. Corrected checks include sustained Tooltip visibility, actual painted Skeleton dimensions and effect names, and inner Page navigation. The later complete browser log is the final completion evidence.

## Principles and review limits

Fix Root Causes removed Skeleton's display override and stopped the initiating Tooltip event at the actual dismissal boundary. Model the Domain kept the existing layout and navigation owners. Laziness Protocol selected direct Page composition over a new facade and removed redundant reference entries. Prove It Works required real interaction, painted geometry and screenshot inspection. Explain the Number distinguished Select's small inner input from its full painted combobox. Attack the Premise rejected the assumption that Page readiness alone explained fragment drift and led to observing all rendered native hosts.

Independent-context review uses gpt-6.1-sol and the same model family as the parent. The initial report is `/tmp/atb-polish-independent-review.md`; the final focused review at `/tmp/atb-polish-final-review.md` reports no unresolved demonstrated finding after tracing the fragment/history boundary, reading completed logs and inspecting eight current screenshots. This is not a diverse-family review or exhaustive interaction testing of every upstream permutation. The earlier package-wide wrapper coverage remains separately reported.
